# Mystery Box BJJ

A digital "draw from the hat" for positional sparring. Tap **Draw** to get a random
power-up or power-down (e.g. *Start with a triangle* / *Partner starts with a triangle*),
then **Start timer** for a 1, 3, or 5 minute round.

## Run

```sh
npm install
npx expo start
```

Expo SDK 57. Edit the card list in `src/cards.ts`.
